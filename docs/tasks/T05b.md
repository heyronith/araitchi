# Task 5b — Chat UX polish: visible thinking + open (bubble-free) AI replies

Repo: `heyronith/araitchi` (run after Task 5 is merged). Read `AGENTS.md` and `docs/STATUS.md` first. Save these instructions as `docs/tasks/T05b.md`. **UI-only task — do not change APIs, tools, or council logic.**

## 1. Show that the system is working (no more empty box)
- **Immediately after Send**, render a status line in place of the empty reply: animated shimmer text **“Thinking…”** with a small elapsed-seconds counter. Never show an empty bordered box.
- **Reasoning:** when the model streams reasoning, show a collapsible **“Thinking”** section that streams live (muted text, smaller font), then collapses to **“Thought for N s”** (click to expand) once the answer starts. Hidden entirely if the model returns no reasoning.
- **Phase status** (replaces “Thinking…” as events arrive):
  - Tools: “Searching papers…”, “Reading web page…”, “Reading repo…”, “Waiting for your approval…” (from tool-call parts).
  - Council: “3 models answering · 1/3 done” → “Comparing answers…” (synthesizer) → final answer streams.
- The status line disappears when the first answer token arrives; errors replace it with the existing inline error + Retry.

## 2. Open, bubble-free assistant replies (like Claude / ChatGPT)
- **Assistant messages:** no bubble, no border, no background — plain text on the page background, using the **full width of a centred reading column** (max ~768px, same column as the composer). Small model label (lab icon/initial + model name) above the reply.
- **User messages:** keep a subtle right-aligned bubble (muted background, rounded), max ~80% of the column.
- **Typography:** 16px body, line-height ~1.7, generous paragraph/list spacing, headings with clear hierarchy; code blocks and tables span the full column width with horizontal scroll.
- **Message actions** (copy, retry, branch switcher, save to memory, cost footer) sit in a compact row under the reply, visible on hover/focus on desktop and always visible on touch screens.
- **Council replies:** the final answer uses the same open layout; member cards and the disagreement panel stay as cards below it.
- Dark and light themes both look right; responsive down to 375px.

## 3. Tests
- Playwright (mock adds a ~1.5 s delay before the first token and a reasoning stream for one model): “Thinking…” visible before the first token; reasoning section appears and collapses to “Thought for …”; council shows “1/3 done”-style progress then “Comparing answers…”; assistant message element has no bubble/border styling (assert via a `data-variant="open"` attribute rather than CSS details).
- Update any snapshot/selector tests affected.

## 4. Finish
Lint, typecheck, format:check, test, test:e2e, build, check:secrets → commit → push → CI green. Update STATUS.

Summary bullets · changed files · command results · SHA + CI URL · deviations.
