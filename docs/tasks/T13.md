# Task 13 — Trust: citation checking, traceability, research plan

## Goals
1. **Citation checking** — fabricated or mismatched citations never pass silently.
2. **Traceability** — claim → source markers for context/tool results; sentence coverage.
3. **Research plan** — milestones + tasks; agents propose, user decides; STATE.md Next steps from open tasks.

## Branch
`t13-trust` from `t12-environment`. Merge/tag `v0.1.5` only after `v0.1.4` (T12).

## 1. Citation checking
- Extract from assistant replies, council member answers, and final answer: DOIs, arXiv ids, URLs, free-text (title / first author / year).
- Resolve via Crossref, arXiv, OpenAlex, Semantic Scholar (**tool broker**: cache, rate limits, in-flight dedupe, OA budget modes).
- Check: (a) exists; (b) metadata match — title similarity ≥ 0.85, year ±1, first author; (c) support vs abstract (`supported | not_supported | unclear`) with the default **scribe** model when abstract available (heuristic offline fallback). Abstract is wrapped as untrusted data.
- Status: `verified · metadata_mismatch · not_found · claim_not_supported · unchecked`.
- Council: check members **before** synthesis; pass statuses to synthesizer (never rely on not_found/mismatch).
- Scribe: never save a record whose only support is a failed citation; "Save paper" only for `verified`.
- UI: inline badges + summary line under the reply.
- Eval: `pnpm eval:citations` — fixture (≥200 cases); `--keyless` for Crossref/arXiv live fakes+mismatches; `--support` / `--live` after OpenAlex reset. Targets: not_found 100%, mismatch ≥ 95%, FP on real ≤ 2%; report each metric with **n** and **95% CI**; support accuracy on contradicted + correct subsets.

## 2. Traceability
- Markers: `[P-n]` papers, `[H-n]`/`[D-n]`… memory, `[T-n]` tools, `[F:path#L10-24]` files, `[E-n]` experiments.
- Post-process: sentences → clickable chips; invalid markers flagged; unmarked = model reasoning (toggleable).
- Footer: "Traceability: n/m sentences sourced". Persist claim→source map on the message.

## 3. Research plan
- `milestones` + `tasks` (owner me|team, status todo|doing|blocked|done, links).
- Plan view (list + board); suggestion cards (accept/dismiss); Run team task → prefilled chat.
- Experiment verdict → suggest linked tasks; STATE.md Next steps from open tasks.
- Tools: `list_tasks`, `get_plan` (read-only).
