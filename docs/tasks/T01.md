## 3. App data, database, settings
- `paths.ts`: app data dir = `process.env.ARAITCHI_DATA_DIR` if set, otherwise `envPaths('araitchi', { suffix: '' }).data` (e.g. `%APPDATA%\araitchi` on Windows). Create it if missing.
- `db/client.ts`: singleton `getAppDb()` opening `<dataDir>/app.db` with WAL mode; runs Drizzle migrations on first open.
- `db/schema.ts` (Drizzle):
  - `settings(key TEXT PRIMARY KEY, value TEXT NOT NULL /* JSON */, updated_at INTEGER NOT NULL)`
  - `secrets(name TEXT PRIMARY KEY, ciphertext TEXT NOT NULL, iv TEXT NOT NULL, tag TEXT NOT NULL, updated_at INTEGER NOT NULL)`
- `settings.ts`: `getSetting<T>(key, default)`, `setSetting(key, value)`, `listSettings()`.
- All route handlers that touch the DB: `export const runtime = 'nodejs'`.

## 4. Encrypted secrets (API keys)
- `secrets.ts` using `node:crypto` **AES-256-GCM**.
- Master key: 32 random bytes stored in `<dataDir>/master.key`, created on first use, file mode `0o600` where the OS supports it.
- Functions: `setSecret(name, value)`, `getSecret(name)`, `hasSecret(name)`, `deleteSecret(name)`, `listSecretNames()`.
- Allowed names (whitelist, reject others): `openrouter_api_key`, `semantic_scholar_api_key`, `core_api_key`, `github_token`.
- **Never** return secret values to the browser, never log them, never include them in errors.

## 5. API routes
- `GET /api/settings` → all non-secret settings. `PUT /api/settings` → `{ key, value }` (zod-validated).
- `GET /api/secrets` → `{ name: string, set: boolean }[]` for the whitelist (booleans only, no values).
- `PUT /api/secrets` → `{ name, value }` (zod: non-empty, ≤ 4096 chars). `DELETE /api/secrets?name=...`.
- `GET /api/health` → `{ ok: true, version, dataDir }`.
- **Local-origin guard** (`security.ts`, applied to every mutating route): reject (403) requests whose `Origin` header is present and is not `http://localhost:<port>` or `http://127.0.0.1:<port>`. This blocks other websites from writing to the local app.

## 6. Server binding
- `dev` and `start` scripts bind to **127.0.0.1 only**, port 3000 (`next dev -H 127.0.0.1 -p 3000`, same for `start`). Document why in README (the app stores API keys).
