# Eval data sources

## Long-horizon recall (`evals/recall/long-project.json`)

Synthetic fixture generated by `buildLongProjectFixture()` in
`src/lib/server/evals/recall-scorer.ts` (~60 sessions, ~100 planted facts with
revisions, distractors, 100 questions). Regenerate with:

```bash
pnpm exec tsx --import scripts/register-server-only.mjs scripts/build-recall-fixture.ts
```

(or delete `long-project.json` and run `pnpm eval:recall --scribe gold` to recreate).

## LongMemEval adapter

Optional `--longmemeval --limit N` adapter is **not implemented** in this repo
yet. If added, record the dataset licence here before enabling in CI.
